# 🥷 NetworkNinjas - Advanced Disposable Email Service

**NetworkNinjas** একটি অত্যাধুনিক, সিকিউর এবং রিয়েল-টাইম ডিসপোজেবল ইমেইল প্ল্যাটফর্ম। এটি ওটিপি (OTP) বাইপাস ডিটেকশন এবং ৩ডি অ্যানিমেশন সম্বলিত একটি প্রিমিয়াম ইউজার ইন্টারফেস প্রদান করে। এটি মূলত ইথিক্যাল হ্যাকার এবং ডেভেলপারদের টেস্ট ব্যবহারের জন্য ডিজাইন করা হয়েছে।

---

## 🚀 মূল বৈশিষ্ট্যসমূহ (Features)
- **3D UI/UX:** Three.js এবং Glassmorphism ব্যবহার করে ফিউচারিস্টিক ডিজাইন।
- **Real-time Delivery:** Socket.io এবং Redis ব্যবহার করে রিফ্রেশ ছাড়াই ওটিপি আপডেট।
- **Anti-Detection:** বড় প্ল্যাটফর্মের ব্লকলিস্ট এড়াতে ডোমেইন রোটেশন লজিক।
- **Robust Backend:** ওরাকল ক্লাউড (Oracle Cloud) এ চলার উপযোগী ডকারাইজড ব্যাকএন্ড।
- **Admin Command Center:** লাইভ ট্রাফিক মনিটরিং এবং ডোমেইন ম্যানেজমেন্ট।
